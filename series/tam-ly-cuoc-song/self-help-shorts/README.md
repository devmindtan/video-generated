# Self-help và lời nhắc cuộc sống

Các Shorts triết lý/tâm lý hiện có; cùng một tập giữ video và thumbnail cạnh nhau.

- Kênh: Tâm lý cuộc sống.
- Hồ sơ và danh sách tập: [series.json](series.json).
- Tra cứu: `npm run projects -- list --series self-help-shorts`.
- Tạo hồ sơ tập: `npm run projects -- create --series self-help-shorts --id <slug-duy-nhat> --title '<Tên tập>' --format <short-hoặc-long> --duration <giây>`.
- `existing` chỉ ghi nhận tập đã có code, không khẳng định đã xuất bản hoặc nghe duyệt.
