# Chuyện dưới đại dương

Bọt Biển và những câu chuyện đại dương; footage chuyển động thật, kiểm tra âm thanh theo môi trường.

- Kênh: Kênh thiếu nhi.
- Hồ sơ và danh sách tập: [series.json](series.json).
- Tra cứu: `npm run projects -- list --series ocean-stories`.
- Tạo hồ sơ tập: `npm run projects -- create --series ocean-stories --id <slug-duy-nhat> --title '<Tên tập>' --format <short-hoặc-long> --duration <giây>`.
- `existing` chỉ ghi nhận tập đã có code, không khẳng định đã xuất bản hoặc nghe duyệt.
