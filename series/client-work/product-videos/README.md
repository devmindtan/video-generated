# Video sản phẩm

Tách nội dung khách hàng khỏi hai kênh nội dung.

- Kênh: Video khách hàng.
- Hồ sơ và danh sách tập: [series.json](series.json).
- Tra cứu: `npm run projects -- list --series product-videos`.
- Tạo hồ sơ tập: `npm run projects -- create --series product-videos --id <slug-duy-nhat> --title '<Tên tập>' --format <short-hoặc-long> --duration <giây>`.
- `existing` chỉ ghi nhận tập đã có code, không khẳng định đã xuất bản hoặc nghe duyệt.
