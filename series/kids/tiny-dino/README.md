# Những chuyến phiêu lưu của Tí Hon

Short và tập dài cùng nội dung; phải dùng footage chuyển động thật và giọng B đã duyệt.

- Kênh: Kênh thiếu nhi.
- Hồ sơ và danh sách tập: [series.json](series.json).
- Tra cứu: `npm run projects -- list --series tiny-dino`.
- Tạo hồ sơ tập: `npm run projects -- create --series tiny-dino --id <slug-duy-nhat> --title '<Tên tập>' --format <short-hoặc-long> --duration <giây>`.
- `existing` chỉ ghi nhận tập đã có code, không khẳng định đã xuất bản hoặc nghe duyệt.
