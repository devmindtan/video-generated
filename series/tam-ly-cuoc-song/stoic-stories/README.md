# Câu chuyện Stoic dài

Các video kể chuyện dài hiện có; giữ thời lượng và bản dựng đã làm.

- Kênh: Tâm lý cuộc sống.
- Hồ sơ và danh sách tập: [series.json](series.json).
- Tra cứu: `npm run projects -- list --series stoic-stories`.
- Tạo hồ sơ tập: `npm run projects -- create --series stoic-stories --id <slug-duy-nhat> --title '<Tên tập>' --format <short-hoặc-long> --duration <giây>`.
- `existing` chỉ ghi nhận tập đã có code, không khẳng định đã xuất bản hoặc nghe duyệt.
